# 또니랑 학습 지도

> 기준일: 2026-08-07
> 목적: 의미 구분은 유지하고, 현재 작업에 필요한 문법만 순서대로 배운다.

또니랑은 기초용과 고급용 언어를 따로 만들지 않는다. 원문과 의미는 하나를 유지하되,
배우는 사람과 작업 단계에 따라 노출 범위를 달리한다. 숨은 변환이나 모드별 다른 문법은 두지 않는다.

## 처음 시작하는 순서

1. [빠른 시작](QUICKSTART.md)의 `10분 첫 실행`을 따라 한다.
2. 숫자 하나를 바꾸고 다시 실행한다.
3. 결과가 왜 바뀌었는지 설명할 수 있으면 0층을 마친다.
4. 구조화된 반복 결과가 필요할 때 1층의 `보임`으로 넘어간다.

각 예제가 기본 제품에서 실행되는지, 정본으로만 정해졌는지는
[현재 제품 지원 상태](PRODUCT_SUPPORT_CURRENT.md)에서 따로 확인한다.

## 0~5층

| 층 | 만들 수 있어야 하는 것 | 처음 배우는 개념 | 아직 몰라도 되는 것 | 주 대상 |
| --- | --- | --- | --- | --- |
| 0. 첫 결과 | 값을 바꾸고 계산한 뒤 확인 | 이름, 값, 계산, `<-`, `.`, `보여주기` | 씨자리, 이름씨, 계약, 구실, 출처 | 모든 처음 사용자 |
| 1. 움직이는 결과 | 채비를 바꾸고 마디별 결과를 공개 | `채비`, `매마디`, 결정적 실행, `보임` | 이름씨, 구실, solver | 수학·물리 실험 작성자 |
| 2. 재사용 부품 | 정의를 다시 쓰고 여러 파일을 연결 | 씨자리, 이름씨, `:`와 `=`, 고정 받는자리, 다중 파일 | 고급 계약, 증거, solver | 프로젝트 작성자 |
| 3. 안전한 프로그램 | 사전·실행 중·사후 요구를 검사 | `먼저`, `내내`, `마치면`, `물림`, `알림`, 명시적 수선, 구실 | 봉인 자료, 외부 solver | 공용 부품·라이브러리 작성자 |
| 4. 자료와 프로젝트 | 출처가 있는 자료를 봉인하고 이동 | 출처, 증거, lock, 판본, 계보, portable | 일반 다중 물리계, DAE | 자료·교과·팀 프로젝트 작성자 |
| 5. 선언형 모델 | 관계식과 초기 조건으로 풀이 계획을 구성 | 상태 변수, 사건, 모형 중간표현, 풀이 방법, ODE·DAE 경계 | 일반 프로그램 작성에는 필요 없음 | 모델·풀이기 작성자 |

위 층은 난이도 라벨이자 선행 관계다. 2~5층을 몰라도 0~1층 프로젝트를 완성할 수 있어야 한다.

## 문법을 관통하는 한 장

| 질문 | 쓰는 표면 | 구분하는 이유 | 처음 노출 |
| --- | --- | --- | --- |
| 이름에 새 값을 넣거나 바꾸나? | `이름 <- 값.` | 실행 상태를 바꾸는 일 | 0층 |
| 이번에 공개할 이름과 값을 만드나? | `(이름: 값) 보임.` | 필드가 호출마다 달라질 수 있는 열린 값꾸러미 | 1층 |
| 이미 정해진 받는자리에 값을 넣나? | `이름=값` | 정의가 정한 고정 받는자리 결합 | 2층 |
| 받는자리를 가진 이름씨를 정의하나? | `(자리...) 인 이름:이름씨 = {...}.` | 재사용 구조의 정의와 구성을 분리 | 2층 |
| 실행 전·중·후 요구를 말하나? | `먼저` / `내내` / `마치면` | 요구 시점을 혼합하지 않음 | 3층 |
| 요구 위반을 중단할까, 알릴까? | `물림` / `알림` | 제어 결과가 다름 | 3층 |
| 세계 값을 구조화해 외부에 공개하나? | `보임` | 실행 진실과 화면 표현을 분리 | 1층 |
| 공개된 값을 어떻게 볼까? | `보기` | 관찰 내용과 표현 방식을 분리 | 1층 후반 이후 |
| 관계식을 어떤 방법으로 풀까? | 명시적 풀이 방법 | 모형과 해결 방법을 분리 | 5층 |

`:`와 `=`는 다른 질문에 답하므로 합치지 않는다. 다만 `:`는 열린 결과를 공개할 때,
`=`는 재사용 부품을 구성할 때 처음 보여준다.

## 각 문서에 붙일 표지

학습 문서와 예제는 앞에 다음 정보를 밝힌다.

- 대상: 초심자 / 프로젝트 작성자 / 라이브러리 작성자 / 모델 작성자
- 선행 개념: 이 문서 전에 알아야 하는 것
- 몰라도 되는 경우: 일반 사용자가 건너뛸 수 있는 조건
- 제품 상태: 기본 제품 / 검증 후보 / 정본만 / 연구
- 실행 위치: CLI / 셀그림 작업실 / 둘 다

## 문서 역할

- `빠른 시작`: 0층 첫 결과만 실행한다.
- `기초 언어`: 0~1층만 가르친다.
- `프로젝트 만들기`: 2층과 다중 파일을 다룬다.
- `라이브러리·계약 안내서`: 3~4층을 다룬다.
- `선언형 모델 안내서`: 5층만 다룬다.
- `전체 언어 참고서`: 모든 표면을 정확하게 실으되 시작 문서 역할을 하지 않는다.
