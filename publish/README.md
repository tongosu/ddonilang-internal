## 중요한 경계

- 내부 SSOT live current는 v24.25.0입니다.
- 공개 Language SPEC current는 v0.5.0이며 내부 SSOT와 별도 계보입니다.
- 문서 current는 parser·runtime·CLI·WASM·브라우저 제품 완료를 뜻하지 않습니다.
- 다국어 안내는 의미 정본이 아니며 사람 검토 전에는 starter translation입니다.
- 봉인된 SPEC 이전판·후보·실패판은 감사 계보이므로 제자리 보존합니다.
