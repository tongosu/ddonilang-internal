# 또니랑 공개 제품 방향 — PRE_RELEASE

이 로드맵은 capability 수준의 방향이다. 출시일, exact feature membership, 내부 RD·ticket·worktree 또는 제품 완료를 약속하지 않는다.

## V1.0 — small complete language

- 작지만 처음부터 끝까지 실행 가능한 언어 subset
- 공식 CLI와 공통 parser/type/canon/runtime 권위
- 결정적 실행과 기본 프로젝트 workflow
- 진실한 support matrix와 최소 사용자 문서

## V1.2 — usability

- 진단·편집·Workbench 사용성
- 자주 쓰는 표면과 기본 라이브러리 보강
- 설치·업데이트·프로젝트 경험 개선

## V1.5 — practical general-purpose

- 실용적인 일반 목적 프로그램 범위 확대
- 표준 라이브러리·외부 경계·프로젝트 도구 보강
- 안정된 배포·기여 workflow

## V2.0 — mathematics and reasoning

- 수학·추론 표면과 검증된 범위의 고급 수치·Tensor·Proof 연계

## V2.2 — science, engineering and advanced computation

- 과학·공학 계산과 더 넓은 typed structure

## V2.5 — state, time, event and world modeling

- 상태·시간·사건·세계 모델링 capability

## V2.8 — deterministic simulation and experiment environment

- 결정적 simulation·실험·재생 환경

## V3.0 — web 2D and mathematical/physical visual creation

- web 2D 제작과 수학·물리 시각화

## V3.5 — AI, education, NuriGym and RL

- AI 지원·교육 workflow·NuriGym·강화학습 생태계

## V4+ — self-hosting, advanced proof, 3D, large deterministic worlds

- self-hosting 연구와 제품화
- advanced proof와 대규모 형식 검증
- 3D 및 큰 결정적 world 실행

각 단계는 앞 단계의 모든 기능을 무조건 포함한다는 뜻이 아니다. 실제 membership과 support status는 해당 공개판의 support matrix와 독립 제품 근거가 결정한다.
