> 구현 경계: G7과 함수 타입 `-->`는 설계 확정, K0~K7·A1 제품 증거는 아직 OPEN이다.


또니랑은 한국어로 상태·시간·원인·실험을 표현하는 결정론 모델링 언어다. Scratch 다음,
Python 전에 놓이는 첫 텍스트 모델링 언어를 지향하며, 세계가 왜 그렇게 변했는지를
읽고 재현할 수 있게 만드는 데 중심을 둔다.

## v0.2.1 설계의 새 초점

- `가씨/나씨/담은씨/된씨` 같은 한글 씨자리로 재사용 가능한 자료와 함수를 정의한다.
- `구실`로 “그릴 수 있음”, “한 마디 진행 가능” 같은 능력 계약을 명시한다.
- 어떤 구현을 골랐는지 build artifact와 replay에 남긴다.
- 실행 중 구현 탐색이나 숨은 dynamic dispatch 없이 compile/build 시점에 결합을 확정한다.
- 구현이 세계를 읽기만 하는지 바꾸는지, 밖일이 있는지, 결정적인지를 계약에 포함한다.
- 함수 타입은 `-->`로 적어 오른쪽 대입 입력 `->`와 구분한다.
- 제한된 사용자 메타프로그래밍 연구는 `씨앗지음`, 생성 증거 묶음은 `지음증거`로 설명한다.

## 읽을 때의 주의

v0.2.1은 출시 전 공개 초안이다. 여기서 “정본”은 설계가 결정됐다는 뜻이지 현재
parser/runtime/CLI/WASM이 모두 지원한다는 뜻이 아니다. 실제 지원은 지원 범위표의
`제품 상태` 열에서 확인한다.
