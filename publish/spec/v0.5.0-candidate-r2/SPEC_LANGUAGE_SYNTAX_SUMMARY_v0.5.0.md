## 선택값과 맺음

```ddn
점수:수? <- 없음.
성공:(수)맺음 <- (수)맺음.$잘됨(값: 10).
실패:(수)맺음 <- (수)맺음.$안됨(이유: "0으로 나눌 수 없습니다").
```

`T?`는 `T` 값 자체 또는 전용 부재값 `없음`이다. `(T,E)맺음`은 성공과
실패를 모두 명시하며, `(T)맺음`은 실패씨가 `글`인 짧은 정본이다.
`#잘됨/#안됨`은 제거됐다. `없음`과 `맺음.$안됨`은 자동 변환하지 않는다.

```ddn
읽은값 <- 대상가리킴 읽기.
값 아니면 되돌림 읽은값.
```

`값 아니면 되돌림`은 성공값을 묶고 실패를 현재 셈씨·움직씨에서 조기
되돌리는 전용 문장이다. 계약문의 `아니면`과 다른 AST 범주다.

## 두루쓰기 머리

```ddn
(값씨:씨자리, 값씨~는 비교할수있음~이라는 구실~을 맡아야함) 두고
(왼쪽:값씨~과~와, 오른쪽:값씨~을~를)
같은지확인하기:참거짓:셈씨 = { ... }.
```

정적 머리에는 씨자리와 구실 요구만, 실행 머리에는 호출 입력만 둔다.
호출 씨자리 추론은 필수 실행 입력만 사용한다. 반환 문맥·optional 입력·
기본값·사용처로 추론하지 않는다. 구실 최종 짧은 syntax는 KS corpus 뒤
결정하므로 위 장문 관계문을 새 제품 지원 주장으로 읽지 않는다.

## 원자·소유 갈래·말결

- 독립 원자: `#이름`
- 소유 갈래: `고름씨.$갈래`
- 고정된 pattern 안의 짧은 갈래: `$갈래`, 부정은 `!$갈래`
- 다음 호출 하나에 적용되는 말결: `$!말결`
- 독립 원자 부정: `!#원자`

`$!#`, `!$!`, `$$` 같은 혼합 사슬은 금지한다. 지원하지 않는 말결은
조용히 무시하지 않고 오류다.

## 값과 정체성

- 결정적 값 비교는 `==`·`!=`다.
- `(대상씨)가리킴`의 정체성 비교는 `===`·`!==`다.
- 참조에 `==`·`!=`를 쓰는 것은 오류다.
- `없음`은 아직 참조가 없다는 뜻이고 `끊김`은 옛 identity를 보존하지만
  대상이 사라졌다는 뜻이다.

## 함수값과 선택값 연산

```ddn
바꾸는함수:(수 --> 수) <- 두배하기.
두배점수:수? <- (점수, 바꾸는함수) 바꾸기.
있음:참거짓 <- (두배점수) 있는가.
비었음:참거짓 <- (두배점수) 없는가.
```

함수씨 정본은 `-->`다. 함수값은 고정 arity이며 variadic을 허용하지 않는다.
동적 입력은 이름형 값꾸러미 하나로 받는다. `바꾸기`는 `없음`이면 함수를
호출하지 않으며 중첩 선택값이나 맺음을 자동 평탄화하지 않는다.

## 값꾸러미

- `(1, 3)`은 고정 길이·순서 민감 위치형 값꾸러미다.
- `(이름: "가람", 점수: 10)`은 필드 이름·값 의미의 이름형 값꾸러미다.
- `(1, 이름: "가람")`처럼 두 형식을 섞거나 이름을 중복하면 오류다.
- 이름형 `==`와 hash는 작성 순서와 무관하다. 관찰·표시 순서는 별도
  `field_order`가 보존한다.
- 열린 필드는 `이름: 값`, 고정 받는자리 결합·주입은 `이름=값`이다.

## 바이트열·글·범위

```ddn
서명 <- 바이트열{ 0x89, 0x50, 0x4e, 0x47 }.
```

바이트열은 글과 다른 불변 byte 순서값이다. `0x`는 소문자이고 정확히 두
hex digit을 쓴다. 글은 유효 UTF-8이며 raw code point sequence로 비교하고
자동 NFC를 하지 않는다. 언어 이름의 resolution·TypeId·lock 이름은 NFC다.
인덱스는 0기준, 범위는 반열림이다.

## 수·단위

`바른수`, `곱수`, `나눔수`, `셈수`를 구분한다. 목표씨가 유일한 자리의
`바른수 → 나눔수`만 정확한 `n/1` 자동 넓히기로 허용한다. 다른 수 변환과
exact→`셈수`는 명시적이다. 정밀도 손실 계산은 `roundTiesToEven`을 쓴다.
물질량은 독립 차원이며 `mol`이 정본 단위다.

## 계승 표면

v0.3.0의 `(이름: 값, ...) 보임.`, 이름씨 `(자리...)인 이름`, 짧은 계약,
표준 보기·모양·장면의 일반 composition 원칙을 계승한다. `보임 {}`는
정본·호환 입력이 아니다.

## 공개 관찰과 표준 그래프 보기

```ddn
(시간: 시간, 각도: 각도) 보임.
```

`보임`은 이름과 단위가 있는 공개 관찰이다. 명시 보기가 없으면 결과표이며
renderer가 그래프 종류·축·단위·보간을 추정하지 않는다. 표준 선반에는 결과표,
마디선, 시간선, 좌표선, 흩어진점, 비교선, 막대, 분포막대, 상자그림, 열지도,
범위띠, 오차범위가 있다. exact module/export 이름은 OPEN이므로 이 후보는
그래프 호출 철자를 선점하지 않는다.

## 공통 모형 문법

```ddn
낙하운동 = 모형 {
  위치:수@m :: (이어감, 처음::고정=100@m, 처음받음, 내줌).
  속도:수@m/s :: (이어감, 처음::어림=0@m/s, 내줌).
  가속도:수@m/s^2 :: (그자리, 내줌).
  위치' =:= 속도.
  속도' =:= 가속도.
}.
```

`모형 {}`가 만드는 값의 씨는 `모형값`이다. `::`는 임의 metadata가 아니라
registry에 등록된 닫힌 역할·권한·보장이다. 주된 역할은 `축`, `이어감`,
`띄엄`, `그자리`, `들임` 중 정확히 하나이며 `처음받음`과 `내줌`은 부가
권한이다. 몸통 작성 순서는 solver·사건·commit 우선순위가 아니다.

- 초기화: `처음::고정=값`, `처음::어림=값`, `처음::계산`
- 실행별 초기값 대체 권한: `처음받음`
- 명시 미지수: `이름::구함`
- 사건: `될때`, `인 동안`, `N마디마다`, `><` 양방향 경계 통과
- 연결: N항 `(같게, 흐르게) 잇기`
- 출력: 선언별 `::내줌`, 실행별 `내줌=(...)`

```ddn
정밀한방법 <- (
  방식: #정밀,
  허용오차: 0.000001,
  내줌간격: 0.01@s
).

실험결과 <- (
  대상=공1,
  들임=(바깥힘: {시간 | 0@N}),
  처음=(위치: 200@m),
  방법=정밀한방법,
  내줌=(위치, 속도, 에너지),
  끝=10@s
) 풀기.
```

`풀기` 바깥의 고정 호출 핀은 `이름=값`이고, `방법` 값 및 `들임`·`처음`
안의 열린 이름형 값꾸러미 필드는 `이름: 값`이다.
