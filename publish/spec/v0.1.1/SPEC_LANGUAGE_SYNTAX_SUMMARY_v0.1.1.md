> authority: internal current SSOT wins on conflict


이 요약은 `SSOT_LANG_v24.14.1.md`의 동결 표면을 직접 투영한다. 교재는 교육
순서의 소비자이며 이 요약의 정본 근거가 아니다.

## 정의·상태·흐름

| 표기 | 뜻 |
|---|---|
| `=` | 값의 정의 또는 상태의 초기 binding |
| `<-` | 이미 존재하는 상태의 명시적 변화 |
| `<<-` | 정적으로 수집되는 파생 흐름. DAG 위상 순서로 한 번 실행하며 순환은 오류 |

다음은 `lang_flow_hook_interaction_v1` 제품 pack에서 실행 검증된 원문 표면이다.

```ddn
채비 {
  입력: 수 <- 0.
  흐름값: 수 <- 0.
  훅실행: 수 <- 0.
  결과: 수 <- 0.
  t: 수 <- 0.
}.

(시작)할때 {
  입력 <- 5.
}.

(매마디)마다 {
  흐름값 <<- 입력 * 2.
  t <- t + 1.
}.

(흐름값 > 8)일때 {
  훅실행 <- 1.
  결과 <- 흐름값.
}.
```

위 예제의 `채비` 초기화 표면은 현재 제품 증거이고, 표의 `=` 정의/초기 binding은
LF05로 고정된 정본 의미다. 설계 확정과 모든 제품 frontdoor의 출력 전환 완료는
같은 주장이 아니다.

`=`을 매 마디 암묵 재평가하는 FRP 의미와 암묵 last-write-wins는 없다. 같은
phase·같은 대상의 여러 쓰기는 기본 오류이며, 병합은 명시 reducer만 허용한다.

## 시간·조건·알림

- 고정 `마디`가 1급 시간 기준이다. 연속 시간은 결정적 세분 근사다.
- `~인 동안`은 지속 조건, `만약 ~이면 ... 아니면`은 분기다.
- 새 알림은 기본적으로 다음 마디에 전달한다. 같은 마디 전달은 명시 표지와 한도를 요구한다.
- 알림 중복은 발생 순서대로 처리하며 자동 합치지 않는다.

## 닫힌 갈래와 오류

- 선택 값: `T?`, 있음/없음.
- 성공·실패: `맺음<T>`, `#잘됨/#안됨`.
- 과거 `결과/#성공/#실패`는 호환 입력이며 새 canonical 출력이 아니다.

## 설계가 고정됐지만 아직 구현 보류인 표면

- `씨자리`, `구실/갖춤/맡음`.
- 새김틀 R3: 사용 `(#태그) 값{...}`, 등록 `(#새김본) 값{...}`.
- `!!{...}` tool-time hole과 `슬기.의도{...}` 계열. AI는 runtime authority가 아니다.

이 항목들은 문서 설계가 확정됐다는 뜻이지 모든 제품 frontdoor에서 실행된다는 뜻이 아니다.


## settings 정본 설계와 평면 호환

settings의 정본 설계 partition은 다음 여덟 절이다.

```text
설정
├─ 문서
├─ 실행
├─ 이야기
├─ 누리
├─ 샘
├─ 거울
├─ 보개
└─ 슬기
```

정본 설계 예시는 다음과 같다. 이 예시는 소유 경로를 고정하며 모든 제품 frontdoor의
구현 완료를 주장하지 않는다.

```ddn
설정 {
  문서 {
    제목: "포물선 실험".
    설명: "중력을 바꾸어 궤적을 비교한다".
  }.
  실행 {
    마디수: 120.
  }.
  누리 {
    씨앗값: 1234.
  }.
}.
```

기존 평면 입력은 다음 닫힌 집합만 이행 호환 대상으로 둔다.

| 평면 호환 입력 | 정본 중첩 경로 |
|---|---|
| `제목` | `설정.문서.제목` |
| `설명` | `설정.문서.설명` |
| `마디수` | `설정.실행.마디수` |

정본 생성기는 중첩 경로만 출력한다. `title/name/desc/이름`은 guideblock 시험
별칭이지 settings 공개 안정 계약이 아니다. 평면 `화면/기본관찰/기본관찰x`와
영어 settings alias는 legacy/test residue이며 새 정본 출력에 쓰지 않는다.

## 난수 씨앗 용어

| 문맥 | 정본 용어 | 상태 |
|---|---|---|
| 난수의 일반 설명 | `씨앗` | canonical terminology |
| 숫자 RNG 설정·code key | `씨앗값` | canonical design |
| 이름 있는 seed streams | `씨앗묶음` | canonical design, implementation evidence pending |
| 과거 입력 | `시앗`, `시앗묶음` | deprecated input compatibility only |

이름 붙은 계산을 뜻하는 기존 `씨앗`과 난수 설명의 `씨앗`은 문맥이 다르다. 코드에서는
난수 설정을 `씨앗값`으로 써서 모호성을 피한다.
