# creator_gaji_round3_ai_prompt_current_ssot_v1

R3 evidence for current-SSOT AI prompt generation.

The static prompt template no longer owns an SSOT version. The generator selects
the version from the same bundle source as the profile file list and bundle hash,
and requires the latest `SSOT_INDEX` and `SSOT_ALL_MANIFEST` filenames to agree.
The golden was generated by the product `ddonirang-tool ai prompt` command.

Internal SSOT `v24.15.1` and public Language SPEC `v0.2.1` remain separate
version namespaces. This pack does not change `docs/ssot/**`.
