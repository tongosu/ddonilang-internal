# seamgrim_view_reaction_authoring_v1

Wave 2B G5의 `만들기 > 수업 구성` 보기·반응 연출 저작 UI를 검증하는 pack이다.

범위:

- 카메라 정책 `fixed/fit/follow` 선택.
- 측정 부품 `angle/length/vector/axes/trail` 선택.
- 의미 닻 선택.
- 조건 `zero_crossing/sign_change/extremum/tolerance_entry` 선택.
- 반응 동작 `highlight/visibility/camera_focus` 선택.
- 명시적 priority 기록과 같은 닻/속성/우선순위 충돌 진단.

새 DDN 문법, 일반 세계 훅, live online reaction 완료, runtime `state_hash` 변경은 주장하지 않는다.
