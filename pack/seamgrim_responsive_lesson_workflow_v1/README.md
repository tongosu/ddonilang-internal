# seamgrim_responsive_lesson_workflow_v1

G6 responsive product workflow gate for the pendulum semantic lesson.

The browser runner opens the real Seamgrim UI at 1440x900, 1280x720,
1024x768, and 390x844. Each viewport checks canvas pixels, layout overlap, live reaction,
semantic cursor, lesson plan activities, and product navigation. Desktop also
checks that the selected graph stays inside its visible graph host. The 1440x900
path also checks lesson-plan authoring roundtrip and publish-space entry.
