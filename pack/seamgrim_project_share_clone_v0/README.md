# seamgrim_project_share_clone_v0

Wave2E G5 product pack for view-link sharing and clone-as-my-version.

This pack is behavior evidence, not a cloud/login/public-sharing claim. The product path is:

1. Save a project through the local same-origin project service.
2. Open a view-capability fragment link in a separate browser context.
3. Confirm the original project is read-only and the edit link is not exposed.
4. Clone through `내 버전 만들기`.
5. Save a clone edit and confirm the original head/content remain unchanged.

No `docs/ssot/**`, DDN syntax, or `state_hash` formula changes are part of this pack.
