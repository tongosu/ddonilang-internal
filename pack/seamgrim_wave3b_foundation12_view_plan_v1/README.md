# seamgrim_wave3b_foundation12_view_plan_v1

Wave 3B G3 pack for explicit `view_plan.v1` semantic bindings across the
Foundation12 curriculum cohort.

The pack fixes product evidence only: each lesson loads an explicit view plan
through the normal lesson metadata path, resolves semantic anchors against real
observation/source targets, keeps view data outside `state_hash`, and renders a
nonblank primary view across desktop, tablet, and mobile viewports.
