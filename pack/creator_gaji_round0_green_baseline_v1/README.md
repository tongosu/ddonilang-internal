# creator_gaji_round0_green_baseline_v1

창작자 가지 Wave 1의 닫힘을 유지하면서 Round 0 직전 네 후속 결함을 수리하는 R0~R7
기계 기준선이다. `r0_baseline.detjson`은 수리 전 실제 독립 재현 결과와 START_HEAD, 기존
dirty 소유권, 허용 대상 경로를 봉인한다.

이 pack은 완료 주장이 아니다. R1~R7 구현·반복 검증이 모두 녹색이 될 때만 최종 aggregate가
`CREATOR_GAJI_ROUND0_GREEN_BASELINE`을 주장할 수 있다. 외부 창작자 성공 수는 0이다.
