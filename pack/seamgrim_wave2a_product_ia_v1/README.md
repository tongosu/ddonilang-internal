# seamgrim_wave2a_product_ia_v1

셈그림 Wave 2A G1의 네 제품 공간 IA 분리를 고정하는 검증 pack이다.

- 제품 경로: `solutions/seamgrim_ui_mvp/ui/index.html`
- browser runner: `tests/seamgrim_wave2a_product_ia_runner.mjs`
- 범위: 배우기 탐색, 실험실 진입, 만들기 `세계 코드/수업 구성` 탭, 배포 공간 분리, 실행 중 역할 토글의 구조적 부재
- 제외: deployment profile 완성, 수업계획 V0 실제 편집기, 새 DDN 문법, runtime `state_hash` 변경

이 pack의 golden은 실행 마커만 검증한다. 실제 제품 행동은 checker가 browser runner로 검증한다.
