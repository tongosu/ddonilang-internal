# seamgrim_project_full_workflow_viewport_v0

Wave2E G8 product quality gate for the durable project workflow.

The browser runner executes the required workflow at `1440x900`, `1280x720`, `1024x768`, and `390x844`:

- open the pendulum lesson,
- edit DDN and `lesson_plan.v0`,
- save as `나의 진자 실험`,
- reopen edit link and verify saved bytes,
- save a new revision,
- open view link read-only,
- clone as a new project,
- restart the local server,
- reopen original and clone,
- verify bounding boxes, keyboard focus, icon accessibility names, canvas nonblank pixels, and deterministic run hash/trace boundaries.

This pack makes no cloud, login, public publish, signing, new DDN syntax, or `state_hash` formula claim.
