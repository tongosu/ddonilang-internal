# studio_classroom_mode_switch_v1

이 팩의 기존 실행 중 `학생`/`교사` 전환 계약은 폐기됐다.

- 상태: `superseded`
- 대체 근거: `SEAMGRIM_WAVE2A_PRODUCT_IA_V1`
- 현재 원칙: 학생/교사는 실행 중 역할 토글이 아니라 배포 시점 구성이다.
- 현재 제품 계약: Run 화면에는 역할 전환 DOM, 클릭 핸들러, 브라우저 전환 artifact가 없다.
- 이 폐기 팩은 ROADMAP_V2 전역 진행률을 소유하거나 복제하지 않는다.

과거 runner는 완료 근거로 사용하지 않는다. 계정, 클라우드, 권한 시스템, parser/runtime,
lesson schema, `state_hash`, `docs/ssot/**` 변경은 이 대체에서 주장하지 않는다.
