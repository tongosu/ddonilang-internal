# seamgrim_wave3b_foundation12_classroom_authoring_v1

Wave3B G4 contract pack for the Foundation 12 teacher lesson authoring workflow.

This pack is not a new DDN language surface. The behavior gate is the paired
checker and browser runner:

- `tests/run_seamgrim_wave3b_foundation12_classroom_authoring_check.py`
- `tests/seamgrim_wave3b_foundation12_classroom_authoring_runner.mjs`

The product workflow edits `lesson_plan.v0` and keeps DDN world source in the
separate world-code tab.
