# onmungchi_10_worlds_pilot_v1

온뭉치/정본말뭉치 100세계에 앞서 `corpus_card.v1` 후보와 수록 5관문을 검증하는 가등급 10세계 pilot이다.

- 대상: 현재 제품의 `representative_v1` 차시 10개
- 기계 확인: pack 실행, 정본 왕복, 결정적 실행 해시, 리믹스 손잡이 형식, few-shot 짝 형식
- 사람 확인: 낭독, 사용자 수록 승인
- 현재 상태: 10개 모두 `검증중`, 수록 확정 0개

원 기획안의 첫 10세계 이름은 착수 후보였으며 자동 채택하지 않았다. 이 pilot은 실제 제품·CLI 근거가 있는 대표 차시를 우선 선택한다.
