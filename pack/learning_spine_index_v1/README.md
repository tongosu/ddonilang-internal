# learning_spine_index_v1

기존 또니랑 교재, 셈그림 세계, 검증 팩, 가나다 좌표를 8단계 배움길로 잇는다.

- 새 교육과정이나 새 로드맵을 만들지 않는다.
- 구현된 기반, 일부 열린 기반, 설계가 열린 자리를 분리한다.
- 교재·가이드, 구현 보고서, 승인 전 제안을 서로 다른 출처 종류로 표시한다.
- source/reflection/implementation/owner 상태 축을 분리한다.
- `landed` 단계는 연결 세계 실행과 단계 증거 관문을 통과해야 한다.
- Python/Rust/JavaScript/Modelica 대응 교과의 완료를 주장하지 않는다.
- 색인의 승격과 SSOT 반영에는 사용자 결정이 필요하다.
