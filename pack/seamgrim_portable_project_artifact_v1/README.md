# seamgrim_portable_project_artifact_v1

G1 contract for the local Seamgrim portable project artifact boundary.

The product file remains `seamgrim.project_snapshot_artifact.v0`. This pack does
not introduce a new stable portable schema. The checker executes
`tests/seamgrim_portable_project_artifact_runner.mjs`, which validates canonical
JSON, SHA-256, byte limits, forbidden fields, prototype pollution keys, and
current snapshot field preservation.
