# ddn_local_project_graph_v1

G0 baseline and later fixtures for the bounded local DDN project graph and local
gaji bridge Wave 1.

This pack starts as an audit baseline. It does not claim local project graph
behavior is closed yet. Later gates extend the same pack instead of creating one
pack per gate.

Scope boundaries:

- no `docs/ssot/**` edits
- no new DDN syntax
- no public registry, Git resolver, remote download, account, cloud, or IDC
- no `state_hash` formula change
- existing one-file project and `seamgrim.project_snapshot_artifact.v0`
  compatibility must remain
