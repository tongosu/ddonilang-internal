# seamgrim_wave3b_foundation12_curriculum_cohort_v1

Wave 3B G2 pack for promoting the fixed Foundation12 lesson cohort into the
default product curriculum catalog.

This pack does not claim canonical national-curriculum alignment. It fixes the
product behavior contract only: twelve lesson cards are present in the active
catalog, browsable by grade/subject, route to the real lesson run screen, and
reject damaged card references through the checker.
