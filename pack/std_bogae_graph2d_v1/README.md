# std_bogae_graph2d_v1

SSOT addendum G4용 표준 보개 graph2d pack skeleton이다.

`graph2d_lowering_fixture.detjson`을 checker가 두 번 lowering해 payload byte 동일성과 `bogae_hash` 경계를 확인한다. 실제 rendering이나 browser smoke는 수행하지 않는다.

- evidence tier: `pack_skeleton`
- closure grade: `닫힘-문서`
- rendering/UI smoke: 없음
- pixel hash truth: 금지
- world state mutation: 금지
