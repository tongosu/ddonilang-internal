# seamgrim_wave3b_classroom_exchange_v1

Wave3B G5 product gate for local `classroom_exchange.v0` lesson bundle export/import.

The pack is intentionally product-facing:

- teacher publish screen exports the current lesson as `kind=lesson_bundle`
- paste/import opens the same lesson in the run screen without runtime role toggles
- deployment profile, package hash, exchange hash, schema, and size tampering are rejected with Korean diagnostics
- no SSOT, parser, runtime semantics, or `state_hash` formula change is claimed
