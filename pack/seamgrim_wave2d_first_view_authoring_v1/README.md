# seamgrim_wave2d_first_view_authoring_v1

Wave 2D first-view authoring product gate pack.

This pack is a small deterministic marker for `run_pack_golden.py`; the product
behavior is verified by `tests/run_seamgrim_wave2d_first_view_authoring_check.py`
and `tests/seamgrim_wave2d_first_view_authoring_runner.mjs`.

Scope:
- first-view toolbar grouping
- responsive primary-view priority
- authoring workspace roundtrip
- lesson card preview skeleton stability
- local review server no-store contract

Boundaries:
- no `docs/ssot/**` edits
- no new DDN syntax
- no runtime `state_hash` formula change
- no login/cloud/server product expansion
