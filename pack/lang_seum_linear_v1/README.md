# lang_seum_linear_v1

G1 product pack for declarative closure SolvePlan S1.

This pack verifies `teul-cli run --solveplan-out` for bounded linear SolvePlan rows, including the `N <= 8` acceptance boundary, `N = 9` rejection, and source-order tie-break behavior. The product path writes `ddn.solveplan.v1` artifacts, while `state_hash_inputs` remains a manifest field only and does not change the state hash formula.
