# seamgrim_first_delight_projectile_v1

셈그림 첫 공개 제품 쐐기 W1의 포물선 첫 세계 동작 증거 팩이다.

- 공개 진입: `?first_delight=projectile`
- 제품 차시: `rep_phys_projectile_xy_v1`
- 호환 별칭: `physics_projectile`, `projectile`
- 첫 화면 조절값: 가로 속도, 세로 속도, 중력
- 필수 동작: 실행, 일시정지, 한 마디, 초기화, 같은 입력 재실행
- 필수 보기 역할: `trajectory_trail`

`trajectory_trail`과 `afterimage`는 보개 메타이며 상태 해시 입력이 아니다. 이 팩은 새 언어 표면이나 새 런타임 의미론의 완료를 주장하지 않는다.
