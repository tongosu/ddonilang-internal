# seamgrim_portable_project_workbench_v1

G2-G5 product workbench contract for exporting the current approved workbench
project as the existing `seamgrim.project_snapshot_artifact.v0` portable JSON
file, importing it through a verified preview without auto-running DDN, and
editing product-layer content descriptors that participate in the artifact hash.
G5 adds visible original/import/clone lineage and local "my version" creation for
received projects.
G6 integrates received projects into `DDN 찾기` and `내 작업` while keeping
`공식 모음` restricted to built-in official projects.
G7 connects received projects to the existing save path as new work and preserves
portable lineage in the saved server artifact.
G9 verifies the same portable workflow across four browser viewport sizes.

Later gates extend the same pack/checker to lineage, search, save, and roundtrip
behavior.
