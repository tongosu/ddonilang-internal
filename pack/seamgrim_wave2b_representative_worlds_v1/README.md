# seamgrim_wave2b_representative_worlds_v1

Wave 2B G7의 대표 세계 3종 수직 검증 pack이다.

대표 세계:

- 진자: 각도재기, 길이재기, 속도 벡터, 궤적, 따라가기 카메라, 극값 반응 rule ref.
- 포물선: 속도 벡터, 궤적선, 맞춤 카메라.
- 일차함수: 좌표축·눈금, 점, 기울기 측정, 그래프 primary view.

검증은 제품 browser workflow로 DDN 원문 접근, WASM 실행 state hash, 주 보기, 관찰 키, 저장·재열기 경로, 수업 구성 왕복을 확인한다.
