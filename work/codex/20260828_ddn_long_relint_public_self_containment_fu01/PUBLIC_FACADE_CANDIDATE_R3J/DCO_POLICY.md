# DCO-first policy candidate

    DCO_VERSION: 1.1
    SIGNED_OFF_BY_REQUIRED: YES_FOR_EXTERNAL_CONTRIBUTIONS
    CLA_REQUIRED_INITIAL_PUBLICATION: NO
    CLA_RECONSIDERATION_GATE: ORGANIZATION_OR_HIGH_RISK_CONTRIBUTION_NEED

public contribution commit은 Signed-off-by trailer를 가져야 한다. maintainer review는
DCO 확인과 별개이며, DCO는 contributor가 제출한 code/docs/assets의 provenance와
third-party rights를 자동 해결하지 않는다.

정확한 DCO 1.1 원문과 링크는 public repository 생성 전에 공식 source에서 별도
custody하고 byte identity를 봉인한다. 이 후보는 DCO 원문을 재작성하거나 최종 법적
문서로 발행하지 않는다.
