# Contribution policy candidate

## 기본 원칙

- initial public contribution은 DCO 1.1 Signed-off-by를 요구한다.
- initial publication에서 CLA는 요구하지 않는다.
- DCO는 technical review, tests 또는 rights audit를 대체하지 않는다.
- public source에 없는 internal evidence를 contributor의 required check로 요구하지 않는다.
- 새 public syntax, stable wire, stable diagnostic, UI redesign은 별도 Owner 결정 없이는
  contribution 범위가 아니다.

각 commit은 contributor가 적용 가능한 DCO를 확인했다는 Signed-off-by trailer를
포함해야 한다.

    Signed-off-by: Name <email@example.com>

force-push, history rewrite와 public main 직접 push 정책은 repository가 실제 생성되고
branch protection이 검증될 때 별도로 확정한다.
