# LICENSE candidate packet

## 상태

    PREFERRED_CODE_LICENSE_CANDIDATE: Apache-2.0
    LICENSE_DIRECTION_DECIDED: YES
    LICENSE_FINALIZATION: OPEN
    OPERATIVE_LICENSE_GRANT_IN_THIS_FILE: NO

Apache-2.0은 Owner가 승인한 코드 license 방향이지만 이 후보에는 license 전문을
착지하지 않는다. 다음이 닫히기 전에는 LICENSE 파일로 개명하거나 public tree에
승격하지 않는다.

- code contributor와 생성물 권리
- docs, lesson/sample, asset, logo/trademark 권리
- third-party selected license와 required notice
- dependency release inclusion
- Owner의 최종 license 승인

이 파일은 법률 의견이나 사용 허가가 아니다.
