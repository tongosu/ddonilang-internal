# V1 첫 사용자 workflow와 예제 역할

| 사용자 단계 | 대표 후보 | 닫아야 할 제품 근거 |
|---|---|---|
| 처음 접함 | HELLO | 안내에서 예제 열기 |
| 실행 | HELLO | CLI/WASM 동일 출력 |
| 코드 수정 | PC01 | `:=` 정의와 `<-` 재결속 |
| 오류 이해 | PC01 negative | exact migration diagnostic, partial state 0 |
| 작은 자료 프로그램 | TENSOR | shape/selection/replacement/canon |
| 시각 결과 | GRID_CURRENT | Rust native grid result → WASM manifest |
| 저장·종료·재열기 | GRID_CURRENT | project identity와 exact revision reopen |
| 확장 showcase | PROJECTILE | rights와 core closure 뒤 별도 Tier 2 |

한 예제가 모든 capability를 증명하게 하지 않는다. 각 예제는 독립 사용자 workflow와
명시된 capability만 소유한다.
