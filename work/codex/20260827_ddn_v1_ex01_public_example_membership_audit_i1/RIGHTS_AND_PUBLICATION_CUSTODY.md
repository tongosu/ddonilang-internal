# 권리·공개 custody

기술적으로 repository에 존재하거나 이미 `publish/` 아래 있다는 사실은 V1 release
membership, 최종 license, 재배포 권리를 자동 확정하지 않는다.

```text
PC01_RIGHTS: OWNER_CONFIRMATION_REQUIRED
PROJECTILE_RIGHTS: OWNER_CONFIRMATION_REQUIRED
HELLO_GRID_TENSOR_RIGHTS: AUDIT_REQUIRED
PUBLIC_SPEC_EXAMPLES: PUBLICATION_PRESENT_FINAL_LICENSE_OPEN
RELEASE_MEMBERSHIP_COUNT: 0
PUBLIC_COPY_COUNT_BY_EX01: 0
```

이번 감사는 파일의 Git provenance와 제품 parser 상태만 사용한다. 저작권자 identity,
외부 기여 혼입, code/docs/assets license 분리는 법적·Owner 검토 전 닫지 않는다.

권리 확인 전에 금지한다.

- `examples/` 공개 대상 경로로 exact copy
- 의미를 유지한다는 주장으로 임의 축약·재작성
- 공개 conformance aggregate 포함
- Apache-2.0 등 최종 license 부여
