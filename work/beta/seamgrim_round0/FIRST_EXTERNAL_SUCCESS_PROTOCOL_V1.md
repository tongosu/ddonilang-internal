# 셈그림 첫 외부 사용자 성공 확인 V1

## 목적

자동화 속도와 실제 사람이 도움 없이 자기 버전을 만들고 남기는 성공 시간을 분리해 기록한다.
Wave 2E 제품 관문과 독립 검토가 끝난 뒤 사용한다.

## 참여자

- 최소 3명
- 권장 구성: 프로그래밍 초심자 1명, 교사 또는 교육자 1명, 프로그래밍 경험자 1명
- 프로젝트 설명을 미리 들은 사람은 별도 표시한다.

## 진행 규칙

- 진행자는 아래 과제를 읽어 주지 않고 화면과 과제지만 제공한다.
- 막혔을 때 바로 가르치지 않는다. 30초 이상 멈춘 위치와 사용자의 말을 기록한다.
- 계정과 로그인을 가정하지 않는다. 검증된 Wave 2E 서버 저장은 시험 환경의 필수 기반이다.
- 화면 녹화는 별도 동의를 받은 경우에만 한다.

## 과제

1. 진자 수업을 찾고 연다.
2. 진자를 실행한다.
3. 처음 각도를 바꿔 다시 움직임을 본다.
4. 그림에서 보이는 각도와 관찰값의 각도가 같은 시점인지 확인한다.
5. 자기 버전에 이름을 붙여 저장한다.
6. 화면을 닫거나 새로 연 뒤 저장한 버전을 다시 연다.
7. 저장한 버전에서 바꾼 처음 각도가 유지되는지 확인한다.
8. 이 수업을 만드는 DDN 원문을 연다.
9. "처음 각도를 바꾸면 무엇이 달라졌는가?"를 한 문장으로 말한다.

5분 핵심 과제 뒤 추가로 보기 링크를 만들고, 진행자가 별도 브라우저에서 연 뒤 `내 버전 만들기`를
시도한다. 이 추가 과제는 핵심 5분 성공 시간과 분리해 기록한다.

## 성공 기준

- 1~7을 도움 없이 5분 안에 완료한다.
- 잘못된 수업으로 이동하지 않는다.
- 실행 결과가 보이지 않는다고 판단하지 않는다.
- 각도 변경 뒤 결과가 달라졌음을 말할 수 있다.
- 저장한 자기 버전을 다시 열었을 때 이름과 변경값이 유지된다.
- 재열기는 `server_durable` 저장 범위에서 성공해야 한다.
- DDN을 찾을 수 있다.

## 기록 항목

- 참여자 유형과 사전 경험
- 시작 시각, 첫 수업 열기, 첫 실행, 첫 변경, 첫 저장, 첫 재열기, 첫 설명, DDN 열기 시각
- 잘못 누른 항목
- 30초 이상 멈춘 화면
- 진행자 도움 횟수와 내용
- 사용자가 실제로 한 말
- viewport와 브라우저
- 성공/부분/실패
- 보기 링크 열기와 복제 성공 여부 및 별도 소요 시간

## 판정

- 3명 모두 도움 없이 1~7을 5분 안에 완료하면 `first_external_creation_success_candidate`다.
- 한 명이라도 주 시각화를 찾지 못하거나 다른 수업이 열리면 제품 결함으로 돌려보낸다.
- 이 결과는 SSOT 반영이나 한국어 Manim 전체 완료의 증거가 아니다.
