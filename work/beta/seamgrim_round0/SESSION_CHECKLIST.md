# 세션 점검표

## 환경

- [ ] First-run reliability가 `RELIABILITY_CLOSED` 상태다.
- [ ] 현재 최고 등급과 미도달 범위를 참여자에게 과장하지 않는다.
- [ ] 서버 재시작·재열기와 backup restore 관문이 통과했다.
- [ ] 같은 배포 주소와 같은 lesson bundle을 사용한다.
- [ ] 브라우저 확대율은 기본값이다.
- [ ] 개발자 도구와 내부 로그 창은 닫혀 있다.
- [ ] 참여자별 빈 관찰 기록을 준비했다.
- [ ] 실제 초대 승인 `ROUND0_INVITATION_APPROVED=1` 여부를 확인했다.

## 진행

- [ ] 시작 시각 기록
- [ ] 포물선 첫 프로젝트 열기
- [ ] 첫 실행
- [ ] 90초 안 첫 실행 여부
- [ ] 값 하나 변경
- [ ] 그래프·궤적 변화 확인
- [ ] 자기 버전 이름 붙이기
- [ ] 첫 저장
- [ ] 화면을 닫거나 새 세션에서 재열기
- [ ] 이름과 변경값 보존 확인
- [ ] 보기 링크 공유
- [ ] 복제하여 내 버전 만들기
- [ ] 첫 의미 설명
- [ ] DDN 열기
- [ ] 잘못 누른 대상
- [ ] 30초 이상 정지
- [ ] 진행자 도움
- [ ] rollback/support 요청 여부

## 종료

- [ ] 결과를 success/partial/failed로 판정
- [ ] 개인 식별 정보가 없는지 확인
- [ ] 세 명을 합치기 전 개별 기록을 보존
- [ ] 제품 결함과 교육 내용 오해를 구분
- [ ] 저장 성공과 단순 다운로드 성공을 구분
- [ ] capability 링크 원문이 기록되지 않았는지 확인
- [ ] 삭제 요청과 철회 요청을 분리 기록
