# 셈그림 Round 0 사용 과제

화면을 보면서 아래 일을 순서대로 해 주세요. 진행자에게 방법을 묻기 전에 스스로 찾아보세요.

1. 포물선 첫 프로젝트를 여세요.
2. 90초 안에 한 번 실행해서 그래프와 궤적을 확인하세요.
3. 값 하나를 바꾸고 다시 실행하세요.
4. 바뀐 그래프나 궤적을 한 문장으로 설명하세요.
5. 자기 이름 대신 비식별 제목으로 저장하세요.
6. 화면을 닫거나 새 브라우저에서 저장한 프로젝트를 다시 여세요.
7. 바꾼 값이 그대로 남아 있는지 확인하세요.
8. 보기 링크를 열어 읽기 전용인지 확인하세요.
9. 보기 링크에서 내 버전으로 복제하세요.
10. DDN 원문을 열어 어떤 값이 바뀌었는지 찾아보세요.

정답을 맞히는 시험이 아닙니다. 찾기 어렵거나 이상하다고 느낀 부분도 그대로 말해 주세요.
