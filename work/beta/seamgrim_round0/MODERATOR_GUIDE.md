# 셈그림 Round 0 진행자 안내

## 시작 전

- 참여자에게 프로젝트 설명이나 화면 사용법을 미리 가르치지 않는다.
- 이름, 연락처 등 불필요한 개인정보를 기록하지 않는다.
- viewport, 브라우저, 사전 프로그래밍 경험만 기록한다.
- 화면 녹화는 참여자가 명시적으로 동의한 경우에만 한다.

## 진행

1. `PARTICIPANT_TASK_CARD.md`를 보여주고 시간을 시작한다.
2. 첫 90초는 포물선 프로젝트를 열고 실행하는지 관찰한다.
3. 5분 동안 사용법 힌트를 주지 않는다.
4. 잘못 누른 항목과 30초 이상 멈춘 위치를 기록한다.
5. 참여자가 혼잣말로 설명하는 내용은 가능한 그대로 적는다.
6. 5분 뒤에도 막혀 있으면 도움을 줄 수 있지만 도움 시각과 내용을 기록한다.

## 금지

- 실행 버튼, 수업 위치, DDN 버튼을 손으로 가리키지 않는다.
- “그래프를 보세요”처럼 정답 방향을 암시하지 않는다.
- 자동화 러너 시간을 참여자의 성공 시간으로 기록하지 않는다.
- 한 명의 성공을 전체 성공으로 일반화하지 않는다.
- capability 링크 원문을 관찰 로그나 채팅에 남기지 않는다.
- 실제 초대나 메시지 발송은 `ROUND0_INVITATION_APPROVED=1` 없이는 하지 않는다.

## 종료

- 성공 여부와 별개로 가장 이해하기 어려웠던 한 곳을 묻는다.
- “처음 보자마자 무엇을 할 수 있을 것 같았는가?”를 묻는다.
- 관찰 기록을 `OBSERVATION_LOG_TEMPLATE.detjson` 형식으로 정리한다.
- 세 명이 끝난 뒤에만 `RESULT_SUMMARY_TEMPLATE.detjson`을 작성한다.
- 삭제 요청이나 철회 요청은 운영 패킷의 절차에 따라 비식별 project id만 기록한다.
