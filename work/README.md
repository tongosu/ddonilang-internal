# work/

AI 협업을 위한 비정본 작업터다.

| 경로 | 역할 |
|---|---|
| `_session_deltas/` | 세션 간 handoff 큐 |
| `erq/` | 근거 필요 질문 큐 |
| `_templates/` | 세션 델타, ERQ, 웹 AI 핸드오프 템플릿 |
| `codex/`, `claude/`, `gemini/` | 에이전트별 임시 작업 사본 |

이 폴더의 내용은 SSOT가 아니다. 반영이 필요하면 `docs/context/proposals/`, `docs/context/all/DEV_SUMMARY.md`, 제품 코드, pack/test 중 적절한 위치로 승격한다.
