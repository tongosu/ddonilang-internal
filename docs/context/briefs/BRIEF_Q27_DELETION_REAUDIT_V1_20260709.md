# BRIEF: Q27 삭제 111~112건 재감사 — "정말 죽은 것" vs "실수로 같이 지운 것"

작성: 2026-07-09 KST
근거: `2e6a956 [Q27] 죽은 체크 삭제`(112개 `.py` 파일 삭제), `docs/context/briefs/BRIEF_BROKEN_CHECKS_DELETION_V1.md`(삭제 기준: "존재하지 않는 `.md` 문서를 필수 참조로 요구"), 90칸 가나다 재검증 에이전트가 표본 확인 중 `ha2`/`ha3` 체커가 이 기준에 안 맞는데도 같이 삭제된 것을 발견.

## 배경

Q27은 `docs/context/reports/BROKEN_CHECKS_AUDIT_V1.md`(Q3)가 "173개 체커가 한 번도 작성된 적 없는 `.md` 문서를 필수 참조로 요구한다"고 분류한 것을 근거로, 상호참조 62건을 제외한 111개(실제 diff로는 112개 `.py`)를 삭제했다.

그런데 방금 별도 재검증에서 삭제된 `tests/run_roadmap_v2_ha2_education_assessment_pack_check.py`(하-2)와 그 짝인 하-3 체커의 삭제 전 소스를 `git show`로 직접 읽어보니, `PREREQ_PA5`/`PREREQ_TA2`/`PREREQ_MA2` 같은 문서 경로 상수를 선언은 해놓고 **실제로 `require_file()` 등으로 그 문서 존재를 검사하는 코드가 없었다.** 즉 이 체커는 애초에 "없는 문서 때문에 항상 FAIL"하는 게 아니라 **실제로는 PASS하던 체커**였다(07-06 재검증 표에도 PASS로 기록돼 있음). 삭제 기준("문서 없어서 항상 실패")에 안 맞는데 같은 삭제 목록에 포함된 것 — 이름 패턴(`roadmap_v2_*` 또는 유사 네이밍)으로 대량 매칭하다 잘못 걸렸을 가능성이 있다.

## 작업

**모든 108~112개 삭제 파일 하나하나를 기계적으로 재검사한다.** 판단이 아니라 사실 확인이다.

1. `git show 2e6a956 --stat --name-status | grep "^D"`로 이번 커밋에서 실제 삭제된 전체 파일 목록을 뽑는다(정확한 개수 확정).
2. 목록에 있는 `.py` 파일 각각에 대해:
   - `git show 2e6a956^:<경로>`로 삭제 직전 소스를 복원해서 읽는다.
   - 그 파일이 선언/참조하는 "필수 문서" 상수(`DOC`, `PREREQ_*`, `REQUIRED_DOC` 등 이름 패턴)를 찾는다.
   - **그 상수가 실제로 `require_file()` 또는 동등한 존재-검사 호출에 인자로 전달되는지** 코드를 직접 추적한다. 상수 선언만 있고 실제 검사 호출에 안 쓰이면 "삭제 기준 미충족"으로 표시한다.
   - `docs/context/reports/BROKEN_CHECKS_AUDIT_V1.md`(Q3) 표에서 이 파일에 대응하는 행을 찾아, Q3가 이 판단을 어떻게 했는지(문서 미존재를 실제로 확인했는지, 아니면 이름/패턴만 보고 분류했는지) 대조한다.
3. 각 파일을 다음 3분류 중 하나로 표기한다:
   - `정말죽음`: 필수 문서가 실제 코드에서 검사되고, 그 문서가 진짜 없어서 항상 FAIL하던 것.
   - `실수삭제`: 필수 문서 검사가 실제 코드에 없거나, 검사 대상 문서가 실제로 존재하거나, 체커를 복원해서 돌려보면 PASS하는 것.
   - `판단보류`: 코드만으로 판단이 애매한 경우(예: 조건부 참조, 동적 경로 등) — 억지로 분류하지 말고 이유와 함께 남긴다.
4. `실수삭제`로 분류된 파일은 **삭제하지 말고(이미 삭제됐으므로 복원하지 말고) 목록만 만든다.** 실제 복원 여부는 사용자가 이 감사 결과를 보고 결정한다 — 이 브리프에서 파일을 되살리지 않는다.
5. `정말죽음`으로 분류된 파일 중 표본(스템별 최소 2개, 가능하면 더 많이)을 골라 `git show 2e6a956^:<경로>`로 복원한 내용을 실제로 실행해보고(`python <복원된 파일을 임시 경로에 저장 후 실행>` 또는 동등 방법으로) 정말 FAIL하는지 재확인한다. 삭제된 파일을 저장소에 다시 커밋하지 말고, 임시 위치(`work/` 하위 등)에서만 실행하고 실행 후 지운다.
